# Hackathon Attestation RAG Client

A conversational AI agent that helps you discover and explore hackathon projects using on-chain attestation data.

## What it does

- **Answers questions** about hackathon projects and participants using verified on-chain attestation data
- **Searches intelligently** through hackathon attestations to find relevant project information
- **Provides context** about the sources used to answer your questions
- **Chat interface** for natural language queries about hackathon data
- **Multi-agent architecture** that collaborates with a specialized retrieval agent to access the RAG backend

## Example queries

- "What projects were built at ETHGlobal hackathons?"
- "Show me AI/ML projects from recent hackathons"
- "Find projects related to DeFi or blockchain infrastructure"
- "What are the most innovative projects from hackathon participants?"

## How to use

Start a conversation with the agent and ask questions about hackathon projects, participants, or specific technologies. The agent will search through verified attestation data to provide accurate, contextual answers with source references.
